# Mashkay Auto Parts — Fleet Commercial Inventory Tracker

Commercial fleet parts inventory tracking application with real-time Firebase cloud database synchronization and local network sharing.

## Quick Start (Running on your local computer)

Whenever you download or update this project, you must install the npm dependencies (including Firebase) first:

### 1. Open Terminal or Command Prompt in the project folder
```bash
cd "C:\Users\USER 20\Desktop\mashkay_inventory\inventory-tracker-main"
```

### 2. Install all required dependencies
```bash
npm install
```
> **Note:** If you recently added Firebase, this step installs the `firebase` package into your `node_modules`.

### 3. Start the application
```bash
npm run dev
```

### 4. Open in your browser
Go to:
```text
http://localhost:3000
```
